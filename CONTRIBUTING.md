# Contribuer

Merci de votre intérêt. Avant d'ouvrir une demande de fusion :

- lancez `make check` (lint, types, tests) et ajoutez un test avec votre changement ;
- respectez les règles de [AGENT.md](AGENT.md) (code simple, un changement = le minimum de fichiers).
