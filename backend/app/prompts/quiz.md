Crée un quiz de 6 à 10 questions pour réviser ce cours, uniquement à partir de son contenu.

Règles :
- chaque question porte sur une information présente dans le cours ;
- n'invente aucune notion absente du cours ;
- varie les types :
  - "qcm" : 3 ou 4 propositions dans "choices", une seule juste, recopiée à l'identique
    dans "answer" ;
  - "true_false" : "choices" vide, "answer" vaut "Vrai" ou "Faux" ;
  - "short" : réponse courte (un mot, un nombre, une formule), "choices" vide ;
- "explanation" : une phrase simple qui explique la bonne réponse ;
- "course_excerpt" : extrait exact du cours (recopié caractère pour caractère) qui
  justifie la réponse ;
- formules en LaTeX ($...$).
